# AITC Logistics Data Processing & Dashboard

## Project Overview
A Python-based dashboard developed to support logistics data processing and sales monitoring. The project combines Excel data handling, MySQL database integration, and Streamlit visualization to provide useful insights into logistics sales data.

## Features
- Excel file processing using Python
- MySQL database integration
- Sales data monitoring and analysis
- Interactive Streamlit dashboard
- Data validation and processing status visibility
- Sales reporting for business decision-making

## Technologies Used
- Python
- Pandas
- Streamlit
- MySQL
- OpenPyXL
- MySQL Connector/Python

## Installation and Setup

1. Clone this repository:
   ```bash
   git clone https://github.com/rushimote19/AITC-Logistics-Sales-Dashboard.git
   ```

2. Navigate to the project directory:
   ```bash
   cd AITC-Logistics-Sales-Dashboard
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Configure your MySQL connection using local environment variables or a private configuration file. Do not commit database credentials.

5. Run the dashboard:
   ```bash
   streamlit run automation_dashboard.py
   ```

## Business Objective
To simplify logistics data processing and provide an accessible dashboard for monitoring sales information and supporting data-driven decisions.
